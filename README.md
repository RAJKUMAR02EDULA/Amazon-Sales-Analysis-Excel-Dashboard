# 📊 Marketing Campaign Data Analysis using Excel

## 📌 Project Overview

This project focuses on analyzing marketing campaign performance using Microsoft Excel. The objective is to evaluate campaign effectiveness, understand marketing channel performance, analyze regional results, and identify opportunities to improve marketing ROI.

The project uses Excel data analysis techniques, formulas, pivot tables, and an interactive dashboard to transform raw marketing data into meaningful business insights.

## 🎯 Project Objectives

- Analyze marketing campaign performance.
- Compare marketing channels based on revenue and spending.
- Evaluate campaign conversion rates.
- Analyze regional marketing performance.
- Track marketing KPIs.
- Identify profitable marketing campaigns.
- Understand the relationship between marketing spending and revenue.
- Support data-driven marketing decisions.

## 📁 Dataset Description

The dataset contains **500 marketing campaign records** with 15 columns.

| Column | Description |
|---|---|
| Campaign_ID | Unique campaign identifier |
| Date | Campaign date |
| Channel | Marketing platform |
| Region | Campaign region |
| Budget ($) | Allocated campaign budget |
| Spend ($) | Actual marketing expenditure |
| Impressions | Total advertisement impressions |
| Clicks | Total advertisement clicks |
| Conversions | Number of conversions |
| Revenue ($) | Revenue generated |
| CTR % | Click-through rate |
| CPC ($) | Cost per click |
| CPA ($) | Cost per acquisition |
| ROAS | Return on advertising spend |
| Profit ($) | Revenue minus marketing spend |

**Dataset Period:** December 2024 – June 2025

**Marketing Channels:**
- Google Ads
- Facebook
- Instagram
- LinkedIn
- Twitter

**Regions:**
- North
- South
- East
- West

## 📈 Key Performance Indicators (KPIs)

The following KPIs are calculated to measure campaign effectiveness:

| KPI | Formula |
|---|---|
| CTR | (Clicks / Impressions) × 100 |
| CPC | Spend / Clicks |
| CPA | Spend / Conversions |
| ROAS | Revenue / Spend |
| Profit | Revenue - Spend |
| Conversion Rate | (Conversions / Clicks) × 100 |
